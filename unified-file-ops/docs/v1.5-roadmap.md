# UFOP v1.5 Roadmap

---

## Vision

v1.5 expands UFOP from a desktop-first file operations platform to a multi-device ecosystem with mobile companion support, modern networking protocols, developer-oriented features, and deeper version control integration.

**Target Timeline:** 6-9 months after v1.1 GA

---

## Major Features

### 1. Mobile Companion App

**Goal:** Provide a mobile app (iOS and Android) that extends the UFOP experience to phones and tablets.

#### Capabilities

- **Browse** files on connected locations from mobile
- **Transfer** files between phone and desktop UFOP instance
- **Camera upload** - Automatically upload photos/videos to a configured destination
- **Approve** transfer requests and sync operations remotely
- **View** transfer and sync status in real-time
- **Notifications** for completed transfers, sync failures, and approval requests

#### Architecture

- Built with Tauri Mobile (Tauri 2 iOS/Android support)
- Connects to the desktop UFOP instance via secure WebSocket
- Lightweight: browse and control, not a full file manager
- Push notifications via APNs (iOS) and FCM (Android)

#### Privacy

- No file content stored on mobile by default
- Preview thumbnails only (not full files)
- All data in transit encrypted (TLS 1.3)

---

### 2. QUIC Peer Transfer Protocol

**Goal:** Replace TCP-based peer transfers with a modern QUIC-based protocol for faster, more reliable transfers.

#### Benefits

- **Multiplexed streams** - No head-of-line blocking for multi-file transfers
- **0-RTT connection** - Faster connection establishment for repeat peers
- **Built-in encryption** - TLS 1.3 integrated into the transport layer
- **Connection migration** - Transfers survive network changes (Wi-Fi to Ethernet, etc.)
- **Better congestion control** - More aggressive utilization of available bandwidth

#### Implementation Plan

1. Adopt `quinn` (Rust QUIC library) for the peer transport layer
2. Maintain TCP fallback for environments that block UDP
3. Benchmark against current TCP implementation
4. Target 2x throughput improvement for small-file bulk transfers

---

### 3. Git Awareness

**Goal:** Make UFOP aware of Git repositories to prevent accidental operations on tracked files and provide developer-friendly features.

#### Features

- **Git status overlay** - Show modified/staged/untracked indicators on files
- **Respect .gitignore** - Exclude ignored files from sync and search by default
- **Branch indicator** - Show current branch in breadcrumb or status bar
- **Diff preview** - Show inline diff for modified text files in the preview pane
- **Safe operations** - Warn before bulk-renaming or moving files in a Git repository
- **Git-aware sync** - Option to exclude `.git` directories from sync pairs
- **Stash integration** - Stash changes before destructive operations (opt-in)

#### Non-Goals

- UFOP is not a Git client. Full Git operations (commit, push, pull, merge) are out of scope.
- Users should use their preferred Git client for version control operations.

---

### 4. CLI Extensions

**Goal:** Expand the CLI to cover all desktop app capabilities and support advanced automation scenarios.

#### New Commands

```
ufop watch <path>         # Watch a directory and report changes in real-time
ufop diff <path1> <path2> # Compare two directories and show differences
ufop mirror <src> <dst>   # One-way mirror (delete files in dst not in src)
ufop mount <uri> <path>   # Mount a remote location as a local path (FUSE)
ufop vault create <name>  # Create an encrypted vault
ufop vault unlock <name>  # Unlock a vault
ufop vault lock <name>    # Lock a vault
ufop peer list            # List discovered peers
ufop peer send <peer> <files> # Send files to a peer
ufop server transfer <src-conn> <dst-conn> # Server-to-server transfer
ufop config get <key>     # Get a configuration value
ufop config set <key> <value> # Set a configuration value
ufop plugin list          # List installed plugins
ufop plugin install <name> # Install a plugin
```

#### Shell Completions

- Generate shell completions for bash, zsh, fish, and PowerShell
- `ufop completions <shell>` command

#### Watch Mode

- `ufop watch` provides a real-time event stream (JSONL) of filesystem changes
- Useful for CI/CD pipelines, deployment scripts, and monitoring

#### Plugin System

- Support for custom connectors as dynamically loaded libraries
- Plugin manifest format for metadata and capabilities
- Plugin marketplace (future consideration)

## Additional v1.5 Enhancements

### Improved Cloud Integration

- **Azure Blob Storage** connector
- **Google Cloud Storage** connector
- **Backblaze B2** improvements (lifecycle policies)
- **Multi-account** support for cloud services

### Advanced Sync Features

- **Partial sync** - Sync only specific folders within a large directory
- **Bandwidth scheduling** - Different sync speeds at different times of day
- **Sync chains** - Trigger one sync after another completes (A -> B -> C)
- **Delta sync** - Only transfer changed portions of files (rsync-like)

### Developer Experience

- **SSH config import** - Import connections from `~/.ssh/config`
- **Dotfile awareness** - Special handling for dotfiles and hidden files
- **Large file support** - Progress tracking for individual large files
- **Parallel operations** - Run multiple file operations concurrently

### Enterprise Features

- **LDAP/Active Directory** integration for admin console authentication
- **SAML/SSO** support
- **Compliance templates** - Pre-built policy templates for GDPR, HIPAA, SOX
- **Data classification** - Automatic file classification based on content analysis
- **Retention policies** - Automated cleanup based on file age

### Accessibility

- **Voice control** integration (platform-specific)
- **Screen reader optimization** based on user testing feedback
- **Custom keyboard shortcut mapping**
- **High DPI / scaling improvements**
